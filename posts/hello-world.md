이 블로그는 **마크다운 파일**을 읽어서 정적인 HTML 페이지로 변환해주는 작은 빌드 스크립트로 만들어졌습니다. 프레임워크 없이 순수한 HTML, CSS, JavaScript만 사용합니다.

## 이 블로그가 지원하는 것들

- 마크다운으로 글쓰기
- 다크 모드 / 라이트 모드 전환
- 모바일에서도 잘 보이는 반응형 레이아웃
- 코드블록 스타일링

## 새 글을 추가하려면

`posts/` 폴더에 `.md` 파일을 추가하고 아래처럼 프론트매터를 작성한 다음, 빌드 스크립트를 실행하면 됩니다.

```bash
node build.js
```

그 다음 `dist/index.html`을 브라우저로 열면 결과를 바로 확인할 수 있습니다.

> 빌드 결과물은 완전히 정적인 HTML이라 별도의 서버 없이도 파일을 그대로 열어서 볼 수 있습니다.

더 자세한 마크다운 문법 예시는 [마크다운 문법 가이드](markdown-guide.html) 글을 참고하세요.
